# Integrations

* [Jira](jira.md) - How this project's Jira is set up - project key, where acceptance criteria live, issue types and the status for each stage; read by /dirox-kit:jira and the other commands
* [LRCLIB](lrclib.md) - Free lyrics service that gives each song's lyrics text and the recording's duration.
* [YouTube audio through yt-dlp](youtube-audio.md) - The song's audio is downloaded from YouTube with yt-dlp for beat and word analysis only, never exported.
