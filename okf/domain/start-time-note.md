# Start-time note

## Definition
A small text file next to the rendered reel: song, artist and the section start in song time, to 0.1 s. The owner sets the Instagram audio to start there when posting.

## Not to be confused with
- The section end: the reel's length decides it.

## Rules
- Sync risk: burned-in lyrics only line up if the Instagram audio starts at the noted time. The owner's times are used exactly; if Instagram's slider is coarse, the owner gives whole-second times. Preview the first reels in Instagram's editor.
